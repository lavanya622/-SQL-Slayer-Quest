# 🚀 SQL Slayer Quest — Day 1

## 🎯 Today's Mission: My First SQL Queries

Started my SQL learning journey using Microsoft SQL Server!

### 📚 What I Learned
- Creating a database using `CREATE DATABASE`
- Selecting a database using `USE`
- Creating a table using `CREATE TABLE`
- Inserting records using `INSERT INTO`
- Retrieving data using `SELECT`
- Filtering records using `WHERE`
- Using comparison operators like `>` and `<`
